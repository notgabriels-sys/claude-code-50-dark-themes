Install Lagoon.

Requires Claude Code v2.1.118 or later. The marketplace command is needed once per machine; the plugin command installs the whole 50 Dark Themes pack. Then run /theme in Claude Code and choose “Lagoon” from the list.

$ claude plugin marketplace add notgabriels-sys/claude-code-50-dark-themes
$ claude plugin install 50-dark-themes@notgabriels-themes

If Claude Code was open while you installed, restart it: plugin themes load when it starts.

> /theme

Plugin themes are read-only. Press Ctrl+E on one in /theme for an editable copy in ~/.claude/themes/.

Or copy just this file.

One theme, no plugin: fetch lagoon.json from the repository into your themes folder. If that folder did not exist when Claude Code started, restart it once.

$ mkdir -p ~/.claude/themes && curl -fsSL https://raw.githubusercontent.com/notgabriels-sys/claude-code-50-dark-themes/main/lagoon.json -o ~/.claude/themes/lagoon.json

Terminal background: #152023.

Claude Code colours its own interface; the terminal application owns the canvas behind it. Every figure below is measured against #152023, so set that as the terminal background for the result the numbers describe. On a different background the ratios move.
