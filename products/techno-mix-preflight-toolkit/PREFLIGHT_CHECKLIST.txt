TECHNO MIX PREFLIGHT - 10 MINUTE CHECK
======================================

SETUP
[ ] Save a new mix revision before making changes.
[ ] Turn the monitoring level down before playing any test tone.
[ ] Disable master limiting only if you can restore the exact approved state.
[ ] Match comparison levels; louder is not automatically better.

ROUTING AND STEREO
[ ] Confirm left-only and right-only files emerge from the correct speaker/channel.
[ ] Confirm the mono-centre file sits exactly in the centre.
[ ] Sum the intentional out-of-phase file to mono and confirm strong cancellation.
[ ] Sum the mix to mono and note elements that disappear or change unexpectedly.

LOW END
[ ] Audition low-end references quietly; record where audibility changes sharply.
[ ] Compare the kick and bass relationship at low volume.
[ ] Check whether kick and bass remain identifiable in mono.
[ ] Inspect overlapping low-frequency notes for inconsistent level or masking.

BALANCE AND TRANSLATION
[ ] Compare the four frequency-focus files without changing monitor level.
[ ] Check the mix quietly for vocal/lead, kick, snare/clap and main rhythmic focus.
[ ] Check on one small or bandwidth-limited playback system.
[ ] Return to the main monitors and make only evidence-based corrections.

EXPORT
[ ] Confirm the correct arrangement, start, end and complete effect tails.
[ ] Confirm no unintended clipping, muted tracks, offline devices or missing media.
[ ] Export the required sample rate, bit depth, channel layout and filename.
[ ] Reopen the exported file and audition the beginning, loudest section and ending.
[ ] Preserve the approved mix and document any mastering notes separately.

This checklist is a decision aid, not a universal mastering specification.
