FINAL AUDIO DELIVERY QC
=======================

IDENTITY
[ ] Correct artist, title, arrangement and approved source version
[ ] Exact expected asset count
[ ] Filenames unambiguous and collision-free

MEDIA
[ ] Every file has a readable header and nonzero size
[ ] Sample rate, bit depth and channel layout match the confirmed brief
[ ] Duration, start point, alignment and tails match requirements
[ ] No unintended clipping, NaNs, dropouts, truncation or unexpected silence
[ ] Loudness and peak values checked only against the confirmed destination brief

AUDITION
[ ] Beginning checked
[ ] Loudest passage checked
[ ] At least one transition checked
[ ] Representative quiet passage checked
[ ] Ending and complete effect tail checked
[ ] Mono and phase behavior checked where relevant
[ ] Stem reconstruction checked where required

PACKAGE
[ ] README / delivery note included when required
[ ] Manifest matches files actually present
[ ] Final archive reopened successfully
[ ] Checksum generated and recorded when material
[ ] Transfer completion verified
[ ] Recipient acceptance recorded separately

VERDICT
[ ] READY — TECHNICAL QC PASSED
[ ] READY WITH DOCUMENTED DEVIATIONS
[ ] RENDERED — QC INCOMPLETE
[ ] PROVISIONAL MASTER / STEMS BLOCKED
[ ] BLOCKED — REQUIREMENTS OR MEDIA MISSING
