# Hypnotic Percussion Grid — product brief

## Commercial position

- Identity: Hologram People
- Product: 64 original percussion one-shots
- Buyer: intermediate and professional techno producers
- Sound: hypnotic, industrial, dry, spatially controlled and suitable for layering
- Format: DAW-agnostic stereo WAV, 24-bit / 48 kHz
- Dependencies: none
- Store: Gumroad first, Bandcamp-ready archive
- Target price: €17

## Content contract

- `01_Closed_Hats`: 16 short high-frequency articulations
- `02_Metallic_Percussion`: 16 tuned and inharmonic metal strikes
- `03_Dry_Clicks_and_Ticks`: 16 micro-percussion sounds for groove detail
- `04_Shakers_and_Noise`: 16 short textured motions
- Total: exactly 64 WAV files

## Design constraints

- No kick drums, risers, impacts, drones or long transition effects; this product must remain distinct
  from the two published packs.
- Every sound must be synthesized from scratch with deterministic generation.
- Preserve useful headroom for sequencing, saturation and bus processing.
- Use zero-valued beginning and ending boundaries and retain complete decay tails.
- No universal loudness normalization across categories.
- File names must identify category and variation without fabricated hardware claims.

## Delivery gates

1. Render all 64 files.
2. Verify exact count, category counts, codec, sample rate, bit depth, channels, nonzero size and duration.
3. Measure true peak for every file against the documented provisional ceiling.
4. Create a representative audition reel covering all four families.
5. Complete human listening approval.
6. Package README, licence and manifest with the WAVs.
7. Seal the final ZIP, reopen it and rerun technical QA from the extracted archive.
8. Create landscape and square artwork derived from the actual reel.
9. Publish only after seller-side attachment read-back and public checkout verification.
