## Long description

Claude Code is powerful, but long agent sessions get messy fast: vague tasks, unclear repo state, missing test plans, half-finished handoffs, and PRs that are hard to review.

Claude Code Workflow Kit is a practical template pack for keeping AI coding sessions organized and useful.

You get ready-to-copy templates for:

- repo audits
- bug investigations
- PR reviews
- release preflight checks
- agent handoffs
- refactor planning
- test planning
- GitHub issues
- project instructions
- client delivery notes

Use them in Claude Code, Codex, GitHub issues, pull requests, client projects, or your own `docs/agent-workflows/` folder.

This is not a prompt-hype pack. It is a lightweight operating system for making agent work easier to start, easier to verify, and easier to resume.
