# Application icon provenance

Generated for Audio Delivery Preflight on 2026-08-21 using OpenAI’s built-in image-generation tool.

Project master: `AppIcon-1024.png`  
Packaged asset: `AppIcon.icns`

Final prompt:

> Create a restrained, professional macOS icon for a technical audio-delivery verification utility. Combine a precise audio waveform, a file or package boundary, and a subtle completed-verification check. Use a premium native macOS utility treatment with crisp geometry, layered charcoal and near-black, warm off-white signal lines, and one muted bronze accent. Keep it legible at small sizes. Use no words, letters, numbers, brand logos, musical notes, headphones, speakers, or watermark. Avoid antivirus and generic-checklist styling.

The generated raster master was normalized to 1024 by 1024 pixels. A multi-resolution TIFF was assembled with 16, 32, 48, 128, 256, 512, and 1024 pixel representations, then converted to the committed `.icns` resource using the macOS `tiff2icns` utility.
