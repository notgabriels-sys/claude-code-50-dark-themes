The chat app only gives you Light / Dark / System. The Claude Code CLI reads custom theme files — so here are fifty, each hand-tuned around a single accent. Drop one in, run /theme, done. Requires Claude Code v2.1.118 or later.

50 themes all dark one .json each hot-reloads status colors stay semantic
install — native Claude Code plugin
01

Use Claude Code v2.1.118 or later

02

Add the marketplace and install 50-dark-themes with the command below

03

Run /theme and pick one. Press Ctrl+E if you want an editable copy

$ claude plugin marketplace add notgabriels-sys/claude-code-50-dark-themes && claude plugin install 50-dark-themes@notgabriels-themes
